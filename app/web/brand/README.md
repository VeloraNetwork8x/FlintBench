# FlintBench brand assets

The logo (a workbench with a flint and its spark) was provided by the owner on 2026-10-07,
made with ChatGPT image generation; the transparent version replaced the first one (on black)
the same day. Master: 1316 × 1195 PNG with transparency (kept by the owner, not in the repository).

Derived files: the drawing (alpha > 50 %) centred on a transparent square with a small margin,
resized with Lanczos:

| File | Size | Used for |
| --- | --- | --- |
| `logo-256.webp` | 256 × 256 | the large logo of the sign-in screens (88 px, sharp up to ~3× screens) |
| `logo-128.webp` | 128 × 128 | the 30 px logo slot: sidebar, setup wizard, welcome sequence |
| `favicon-32.png` | 32 × 32 | browser tab (lightly sharpened) |
| `favicon-64.png` | 64 × 64 | browser tab on high-density screens |

Margins: 4 % around the drawing for the logos, 2 % for the favicons. The 512 px copies are not
shipped: nothing in the console shows the logo that large.
